# AuraWatch Ultra - Promotional Website Project

> **Project Group:** Group 2  
> **Assigned Project:** 10. Technology Product Website  
> **Course / Activity:** Creative HTML & CSS Webpage Projects (Activity 2)

---

## ⚡ Project Overview
**AuraWatch Ultra** is a high-tech promotional showcase webpage for an aerospace Grade 5 titanium flagship smartwatch. Designed with modern dark-mode aesthetics, glowing accents, and bento-grid layouts, it features deep hardware specifications, real-time vital telemetry highlights, professional tech reviews, multi-tier pricing, and an interactive pre-order checkout form.

---

## ✨ Features Included
- **Sticky Glassmorphism Header:** Floating header with product branding, navigation links, and pre-order call to action.
- **Hero Presentation:** Radial glow backdrop, punchy headline, dual callouts for 3,000-nit MicroLED display and 100-hour battery life.
- **Hardware Highlights Bar:** Quick-glance icons for Titanium grade, 100m water resistance, dual-frequency GPS, and BioCore sensors.
- **Bento Feature Grid:** Asymmetric grid highlighting cardiovascular ECG telemetry, satellite emergency SOS, and dual 86dB siren controls.
- **Comprehensive Technical Specifications:** Structured spec sheet detailing case dimensions, weight, battery cycles, display resolution, sensor suites, and OS compatibility.
- **Critic & Endurance Reviews:** Featured quotes from top tech publications (TechPulse, Outdoor Endurance, The Gadget Review).
- **Interactive Multi-Edition Pricing:** 3 editions (Trail Explorer $399, Ocean & Apex $499, Ceramic Executive $649) with band color selectors.
- **Pre-Order Checkout Modal Form:** Shipping and model reservation form with 30-day money-back guarantee.
- **Modern Footer:** Technical documentation links, customer support resources, and firmware updates newsletter.

---

## 💻 Tech Stack
- **HTML5:** Semantic architecture (`<header>`, `<nav>`, `<section>`, `<article>`, `<form>`, `<footer>`).
- **CSS3:** Custom properties (CSS variables), CSS Bento Grid, Flexbox, glow filters, and responsive media queries.
- **Typography:** Google Fonts (`Space Grotesk` & `Inter`).
- **Responsive Design:** Fluid layout across phones, tablets, and high-DPI desktop screens.
